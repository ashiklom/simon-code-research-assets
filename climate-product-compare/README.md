# climate-product-compare site data

Per-site Parquet/JSON files read by the interactive site of
[simon-code-research/climate-product-compare](https://github.com/ashiklom/simon-code-research/tree/main/climate-product-compare)
(https://ashiklom.github.io/simon-code-research/climate-product-compare/).

Generated by `mise run sitedata` in that experiment; layout and encoding are documented in
`src/cpc/export_site.py` there. The site fetches these files directly from
`raw.githubusercontent.com` at a pinned commit.
